# Lab 3: Snake Game

A simple Snake game created with Python and Pygame for my A.I. for Game Programming class.

In this game, the player controls a snake that moves around the screen and collects food. The goal is to collect food while avoiding collisions with the walls and the snake's own body.

## Features

- Keyboard-controlled snake movement
- Food that appears on the screen
- Snake growth when it collects food
- Collision detection
- Game-over conditions

## How to Play

Use the arrow keys to move the snake
